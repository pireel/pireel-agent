# The studio UI, as the user sees it

Vocabulary first: **组件 / Component** is Studio's broader extensible visual-element concept. **动态图形 / Motion Graphic** is the primary Component family currently exposed in the UI: kinetic words, one-number reveals, data stories, logo stings, overlays and real-source highlights. Do not treat the two terms as synonyms or assume every future Component is a Motion Graphic. Other user-facing terms: **分镜/场景** (the segments of the visual track — clips over MCP), **取景** (clip framing: full / punch-in / corner / split), **字幕** (global caption presets), **主题** (Frames: professional art directions, not Scene/layout templates; applied through the agent), **素材** (assets: images/videos/Components), **口播稿** (the spoken transcript). Over MCP a Component is a graphic clip on the graphics track.

## Layout

- **Projects home** (`/studio`): project cards — new / open / rename / delete. One project may contain multiple independently editable outputs.
- **Workbench** (`/studio/<id>`), one screen:
  - **Header** (top) — back to projects, light/dark theme, **导出** (export), credits balance and the account menu.
  - **Left column** — **Chat** (the built-in agent) and **字幕稿** (the transcript editor) share it; the switch sits under the chat input.
  - **Preview canvas** (center) — this IS the editing surface: click an element to select it (drag/resize/rotate handles, with its toolbar above the selection), double-click text to edit it in place. The canvas ratio picker sits at its bottom-right. Selecting a component opens its properties on the right automatically.
  - **Right panel + icon rail** — **素材** (my assets / official assets / library: images, videos, audio, stickers and Components; upload, search, insert or drag onto the canvas/timeline), **字幕样式** (caption look, animation and translation line), **文字** (text presets), **音频** (level / fades / speed of the selected audio, narration denoise) and **音色** (voices).
  - **Bottom** — output tabs (each output is an independent timeline; **＋** adds one; the button at the far left collapses/expands the timeline), the transport bar (play, time, undo/redo, add text, split / trim at the playhead, delete selection, person matte, audio), and the **timeline**: typed visual, Component/graphics, audio and caption tracks. Drag assets in, drag clips around, box-select, and apply split/trim/delete to the selection.
- **字幕稿 (transcript editor)** — the narration as continuous text in paragraphs; click a word to jump there, playback follows along.
  - Select words → a toolbar: **添加** (text title / sticker / image or video / sound effect / Motion Graphic — a popover to pick from the library or generate with AI from a drafted prompt, landing on the selection's time range), **编辑** (fix the caption wording), **高亮** (highlight the words; colored by the caption style unless a color is picked), delete (cuts the words from the video), **更多** (bleep / star out words).
  - Pauses longer than 0.4s show as time labels; click one to delete it or add something in it.
  - **口播清理**: shorten every pause longer than 0.4s to 0.3s, or remove hesitation fillers. **自动高亮**: AI highlights the words worth emphasizing across the transcript (undoable).
- **字幕样式 (caption style)** — three tabs: **外观** (artistic and basic looks, plus font, size, bold, text color, highlight color and plate), **动效** (motion, independent of the look) and **副字幕** (a simple look for the translation line).

## Where things run

- Editing, preview, and **export** are local in the user's browser (WebCodecs; export downloads straight to their Downloads folder).
- User-local video, image and audio bytes stay in device-local OPFS; project structure and local locators sync, but the source bytes do not silently upload for device switching.
- The studio tab must be open for video-dependent agent work (transcription, visual analysis, inspect_timeline, export); pure data edits also work with the tab closed (offline mode, against the cloud project). An agent with a built-in browser can open a pre-signed-in editor tab itself (create_browser_handoff) — the user just watches the edit happen.

## Common "where do I…" answers

- Add a Motion Graphic → 字幕稿: select the line → 添加 → Motion Graphic (pick a ready Component or generate one from a drafted prompt), or 素材 → official assets → Components, or ask the agent (BYO compose). For complete edits it should be designed as one layer of the current passage, with real placement/backdrop decided before generation.
- Change how the video is framed in a scene → select the scene card → 取景 button (or the framing badge on the card). (Agent: `set_clip_framing`.)
- Color-grade a scene (brightness/contrast/saturation) → same 取景 window, 画面调色 sliders (100 = untouched; per scene, or ask the agent: `set_clip_properties` with `filter {brightness, contrast, saturate}`, 1 = untouched).
- Clip sound (volume/mute of a scene's own audio, e.g. quiet a B-roll insert) → same 取景 window, 声音 section (volume 0–100% of source level + mute toggle; per scene, or ask the agent: `set_clip_properties` with `volumeDb` -60..+20 / `mute`; linked audio is addressed by the nested `audio.clipId`).
- Narration / music / SFX → typed audio lanes (bottom), drawn with waveforms. User-local audio stays in OPFS; generated/cloud audio keeps its own cloud locator. Drag an audio asset onto the timeline or use its 加到音轨 action. The agent places audio with `add_clips` and declares the intended role (`narration` / `music` / `sfx`) — `register_media` first only for generated or remote audio — then levels and fades it with `set_clip_properties` (`volumeDb`, `fades` in frames). On a clip: body-drag moves it, the two edges trim in/out, the top-corner knobs drag the fades, click selects and Del removes. While an audio clip is selected the toolbar's split / trim-left / trim-right act on it. 音频 is a tab in the assets rail (after 字幕): with a lane clip selected it edits that clip's volume / fade-in / fade-out / speed; with none selected it edits the footage's own sound. Several tracks may overlap and sum.
- Narration denoise → same 音频 panel, 口播降噪 toggle + strength (on-device model, bakes once per source in the background; strength re-blends instantly; or ask the agent: denoise_audio). Needs the studio tab open — it processes audio in the browser.
- Add B-roll → hover a scene card's edge → the「+」button (or ask the agent: import it locally, then `add_clips` role `broll` for an overlay or `insert_clips` to ripple it into the spine).
- Transitions (true dual-stream, rendered by the gl-transitions shaders) → click the narrow band on any cut between scene cards → pick an effect card in the docked panel (无/叠化/渐黑/推移/划开/圆形/百叶窗/变焦/旋转/故障/波浪; hover a card to watch it play on two photos; 推移/划开 have a direction picker). Once set, an accent region straddles the cut on the main track — drag its side handles to adjust length (symmetric around the cut, max 4s); you can't split inside it, and deleting either adjacent scene clears it. Or ask the agent (add_transition).
- Clean up the speech → 字幕稿: select words and delete them, or 口播清理 to shorten pauses and remove fillers in one go. (Agent: `remove_silence`, `remove_words`.)
- Subtitles → 字幕样式 panel → pick a look and an animation (applies to the whole piece; drag/scale on the canvas adjusts all of them). Emphasize words → select them in 字幕稿 → 高亮, or 自动高亮. (Agent: `set_captions` with `on` / `preset` / `animation` / `highlightColor` / `highlights` / `yPct` / `scale`; captions are one managed object, never individual cues.)
- Bilingual subtitles → translate from the transcript editor (字幕稿), style the second line in 字幕样式 → 副字幕: pick a target language and Pireel's own LLM translates (charges credits); or ask the agent to translate itself (free, `set_captions {translations}`) — either way the translation line appears under the captions.
- Change the whole look → ask the agent to apply a Frame (`manage_frame`).
- Get the final file → 导出 in the header (or ask the agent: `export {action:"start"}` then `export {action:"status"}`).
